Where do I get the folder?
  1. Buy Fallout 2 on GOG. It's DRM-free and comes with a plain offline installer. A copy from Steam or Epic works too.
  2. GOG on a Mac or Linux: from your GOG library, download the offline backup installer (setup_fallout2_*.exe), then unpack it: 
    brew install innoextract        # Linux: sudo apt install innoextract
innoextract setup_fallout2_*.exe -I app
mv app Fallout2
    The Fallout2 folder is the one to drop here.
  3. GOG on Windows: run the installer. The folder ends up at C:\GOG Games\Fallout 2.
  4. Steam on Windows: Library → Fallout 2 → Manage → Browse local files.
  5. Steam on a Mac: the Steam app won't download it there, but SteamCMD will. It asks for your password and Steam Guard code: 
    brew install --cask steamcmd
steamcmd +@sSteamCmdForcePlatformType windows +force_install_dir ~/Fallout2 \
  +login YOUR_STEAM_NAME +app_update 38410 validate +quit

The page only keeps what the game needs: the .dat archives, the data and sound folders, the config files, and any saves. Installers, executables and manuals are skipped.

Good to know

  • Saves live in this browser. Use Download saves now and then: clearing site data, or the browser running low on space, can wipe them.
  • Built for a desktop browser with a mouse. Touch works like a trackpad: drag to move the cursor, tap to click, two-finger tap to right click.
  • Saves from the PC version work both ways. Saves in your folder's data/savegame are brought in the first time you add the game.
